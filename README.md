# Software Engineering Lab Project Portfolio

Interactive Software Engineering Laboratory Portfolio covering end-to-end SDLC phases for two real-world case studies:
1. **Cinetix** — Smart Multiplex Ticketing & Concession Management Platform
2. **Mobile Stock Management System** — Retail Inventory & Billing Platform

## 🌐 Live Demo
The site is hosted on GitHub Pages:
**[https://faizanmomingit.github.io/software-engineering-portfolio/](https://faizanmomingit.github.io/software-engineering-portfolio/)**

---

## 📚 Experiments Included
- **Experiment 1:** Problem Statement & Project Scope
- **Experiment 2:** Software Requirements Specification (SRS - IEEE Std 830-1998)
- **Experiment 3:** Estimation using COCOMO Model
- **Experiment 4:** Class Diagrams (UML 2.5)
- **Experiment 5:** Object Diagrams
- **Experiment 6:** Use Case Diagrams & Specifications
- **Experiment 7:** State Transition Diagrams
- **Experiment 8:** Activity Diagrams
- **Experiment 9:** Unit Test Cases & Traceability Matrix
- **Experiment 10:** Entity-Relationship (E-R) Diagram & Relational Schemas
